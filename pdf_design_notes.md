# PDF Design Inspiration

## Timeline Template Analysis

### Key Design Elements:
1. **Curved/winding path** - Creates visual journey feeling
2. **Colored milestone circles** - Blue, Orange, Yellow, Green progression
3. **Icons in circles** - House, Car, Money symbols
4. **Year labels** - Clear timeline markers
5. **Descriptive text** - Explains each milestone
6. **Horizontal arrow timeline** - Clean, left-to-right progression
7. **Colorful chevron arrows** - Forward momentum feeling

### Nickle Brand Colors (from logo):
- Primary Green: #22C55E (green-500)
- Accent Blue: #3B82F6 (blue-500)
- Orange: #F97316 (orange-500)
- Purple: #A855F7 (purple-500)

### Timeline Design for BEFORE Mode PDF:
- **Start Point (Today)**: Blue circle with "Start Saving" icon
- **Milestone 1 (Car Deposit Saved)**: Orange circle with car icon
- **Milestone 2 (House Deposit Saved)**: Green circle with house icon  
- **End Point (Dreams Achieved)**: Purple circle with celebration icon

### Layout Structure:
1. **Page 1**: Branded cashflow statement (current design enhanced)
2. **Page 2**: Beautiful timeline infographic showing savings journey
   - Horizontal timeline with colored milestones
   - Monthly savings breakdown
   - Target dates for each goal
   - Progress indicators
